# 주간 분석 재검토

실행: `python "lotto/로또 당첨번호 예측.py"`

1. 한국 시간 토요일 21시를 결과 공개 확인 기준으로 최신 완료 회차를 계산하고, 누락 회차를 수집합니다. 발표 지연 또는 조회 실패 시 재실행이 필요합니다.
2. 전체 이력을 검증하고 마지막 회차를 공식 조회 결과와 비교합니다. 최신 회차 누락, 공식 조회 실패, 결과 불일치 시 새 예측 저장을 중단합니다.
3. 저장된 지난주 예측을 실제 본번호와 비교합니다. 기록이 없으면 성과를 추정하지 않습니다.
4. 최근 24회를 각 추첨 직전 이력만으로 재예측합니다. 기존 분석 특징을 결합한 보정 모델의 반영 강도 0%, 25%, 50%, 100%를 Brier 오차로 비교합니다. 이 강도는 기존 모델과 균등확률 사이의 혼합 비율입니다.
5. 최저 오차 모델과의 회차별 차이가 표준오차 이내라면 더 낮은 강도를 선택합니다. 검증 회차가 12개 미만이면 균등확률로 돌아갑니다. 지난주 결과 하나만 보고 특정 번호에 가중치를 주지 않습니다.
6. 선택된 강도로 모든 최신 데이터를 다시 학습한 뒤 다음 회차 10세트를 생성합니다. 동일 점수의 번호는 회차별 고정 시드로 순서를 정해 작은 번호 우선 편향을 피합니다.
7. 생성 근거와 지난주 적중 결과는 `주간분석검토_회차.json`에 저장합니다. 기존 회차 번호는 자동 교체하지 않으며 기존 최종 검증 절차는 유지합니다.

강도 선택에 사용한 검증 오차는 조정 근거이며 독립적인 성능 입증 자료가 아닙니다. 조합점수는 당첨확률이 아니며, 과거 분석으로 무작위 추첨의 예측력이 보장되지는 않습니다. 조합 순위화 방식은 유지하므로 세트 간 번호 중복은 가능합니다.

검증: `python -B -m unittest discover -s lotto -p "test_lotto*.py"`
