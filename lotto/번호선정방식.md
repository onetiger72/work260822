# 번호 선정 방식

현재 기본 생성기는 `lotto_portfolio.py`의 `screened_balanced_v5`입니다.

기법별 검증에서 근거가 부족한 특징을 제외하고, 별도 후속 구간에서 결합 모델 반영 강도를 결정합니다. 각 과거 시점의 이력만 사용합니다. 자세한 순서는 `주간분석개선.md`에 있습니다.

기존 상위 점수 조합 10개 선택은 공통 번호를 과도하게 반복했습니다. 현재 방식은 사용 횟수가 적은 번호를 우선 선택하고, 같은 번호쌍의 재사용을 줄인 뒤 모델 점수로 우선순위를 정합니다. 완전히 동률이면 회차에 따른 고정 시드로 결정합니다. 동일 입력·동일 시드는 같은 결과를 냅니다.

10세트 전체로 1~45를 모두 포함하며 한 번호는 최대 2번 사용합니다. 이 때문에 전체 세트가 동시에 본번호 0개가 되는 경우를 막지만, 한 세트가 0개 적중하는 경우는 여전히 가능합니다. 이러한 분산 효과는 당첨번호 예측력을 입증하지 않으며 당첨이나 3개 이상 적중을 보장하지 않습니다.

CSV의 종합점수는 번호별 포함 추정치의 합입니다. 1등 확률이 아닙니다. 균등확률이면 모든 세트 점수는 0.8입니다. 이전 집중 선택기와 모의 선택기는 비교용으로 남겨 두었습니다.

2026-09-28 점검에서는 기법 12개 모두 적용 기준을 통과하지 못했습니다. 보너스 보조 신호는 기존 정책에 따라 별도 제외됩니다. 현재 실제 적용하는 특징은 없으며 균등확률과 번호 노출 분산을 사용합니다.

1184~1243회 회고 비교에서 세트당 평균 본번호 적중은 기존 0.7833, 수정 0.7750, 무작위 100회 반복 평균 0.8048입니다. 회차별 10세트 최고 적중 평균은 각각 1.5000, 2.1667, 2.0860입니다. 평균 적중 자체가 증가한 것은 아니며 무작위 대비 예측 우위도 입증되지 않았습니다.
