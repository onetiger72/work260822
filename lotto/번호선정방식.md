# 번호 선정 방식

현재 기본 생성기는 `lotto_portfolio.py`의 `screened_weighted_balanced_v6`입니다.

기법별 검증에서 근거가 부족한 특징을 제외하고, 별도 후속 구간에서 결합 모델 반영 강도를 결정합니다. 각 과거 시점의 이력만 사용합니다. 자세한 순서는 `주간분석개선.md`에 있습니다.

기존 상위 점수 조합 10개 선택은 공통 번호를 과도하게 반복했습니다. 현재 방식은 사용 횟수가 적은 번호를 우선 선택하고, 같은 번호쌍의 재사용을 줄인 뒤 확률 크기에 따른 가중 추출로 결정합니다. 동일 입력·동일 시드는 같은 결과를 냅니다.

가중 추출은 각 후보의 `-log(U) / (q / (1-q))`가 작은 순서입니다. 여기서 U는 고정 시드 난수이고 q는 검증 후 강도를 적용한 추정치입니다. v5처럼 q의 순위만 비교하면 25%, 50%, 100%가 같은 순위를 가져 같은 조합이 나올 수 있습니다. v6는 q의 크기를 사용하므로 강도가 선택에 영향을 줄 수 있습니다. 다만 노출/번호쌍 규칙이 우선이며 강도마다 반드시 다른 번호가 나오는 것은 아닙니다. 입력 q가 최종 선택 빈도와 정확히 같다는 뜻도 아닙니다.

10세트 전체로 1~45를 모두 포함하며 한 번호는 최대 2번 사용합니다. 이 때문에 전체 세트가 동시에 본번호 0개가 되는 경우를 막지만, 한 세트가 0개 적중하는 경우는 여전히 가능합니다. 이러한 분산 효과는 당첨번호 예측력을 입증하지 않으며 당첨이나 3개 이상 적중을 보장하지 않습니다.

CSV의 종합점수는 번호별 포함 추정치의 합입니다. 1등 확률이 아닙니다. 균등확률이면 모든 세트 점수는 0.8입니다. 이전 집중 선택기와 모의 선택기는 비교용으로 남겨 두었습니다.

기법이 적용 기준을 통과하지 못하면 균등확률과 번호 노출 분산을 사용합니다. 보너스 보조 신호는 본번호 특징에서 정책상 제외합니다. 실제 적용 기법은 각 실행의 `effective_methods`로 확인하며 이전 실행의 판단을 고정하지 않습니다.

2026-09-28 v6의 1183~1242회 비교에서는 60회 모두 신호가 제외되어 같은 선택기·시드의 균등확률 대조군과 조합이 일치했습니다. 세트당 평균 본번호 적중은 둘 다 0.8017, 일반 무작위 100회 평균은 0.8042였습니다. 분산 효과와 학습 효과를 구분해야 하며 무작위 대비 예측 우위는 입증되지 않았습니다. 상세 절차와 수치는 `.agent/AGENT.md`에 있습니다.
