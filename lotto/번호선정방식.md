# 번호 선정 방식

본 실행 파일 `로또 당첨번호 예측.py`의 기본 생성기는 `lotto_portfolio.py`의 `ranked_six_v3`입니다.

기존 과거 패턴 점수를 실제 다음 회차 본번호와 연결해 보정하는 학습은 유지했습니다. 각 학습 입력은 해당 결과보다 앞선 회차만 사용합니다. 최종 선택은 무작위 후보와 모의 추첨 대신, 번호별 포함 추정치의 오즈 곱이 가장 큰 서로 다른 6개 조합 10개를 우선순위 큐로 탐색합니다. 독립 포함 모델을 정확히 6개 선택에 조건화한다는 가정 아래 상위 조합을 찾으며, 실제 추첨 확률을 알아낸다는 의미는 아닙니다.

한 세트 안에서 번호는 중복되지 않으며, 핵심 번호는 여러 세트에서 반복할 수 있습니다. 동일 입력은 시드에 관계없이 동일 결과를 냅니다. 점수가 모두 같으면 번호 순서로 동률을 해소하므로 작은 번호에 집중될 수 있으며, 그 번호가 더 유리하다는 뜻은 아닙니다. 집중 선택은 여러 세트가 함께 빗나갈 가능성도 높입니다.

CSV의 `조합점수`는 기존 호환성을 위해 번호별 포함 추정치의 합을 유지합니다. 최종 정렬 기준인 오즈 곱이나 1등 확률과는 다릅니다. 기존 모의 추첨 선택기는 비교용 `select_simulated_portfolio`로 남겼습니다. 기존 예상번호 CSV는 이번 변경으로 재작성하지 않았습니다.

검증: `python -m unittest discover -s lotto -p 'test_lotto*.py' -q` — 19개 통과. 축소 후보 전체 열거와 상위 조합 일치, 시드 독립성, 핵심 번호 반복, 데이터 시간 순서 등을 확인했습니다.

`python lotto/benchmark_portfolio.py`로 실행한 저장 이력 마지막 60회 회고 검증 결과는 `portfolio_evaluation.json`에 있습니다. 기존 특징 캐시를 사용한 결과로, 독립적인 미래 실전 검증은 아닙니다. 세트당 평균 적중 0.8167개(랜덤 100회 반복 평균 0.8041개), 회차별 10세트 최고 적중 평균 1.2667개(랜덤 2.0863개)였습니다. 6개 일치는 없었습니다. 랜덤 대비 우월성을 입증하지 못했으며, 이 결과를 보고 매개변수를 재조정하지 않았습니다.
