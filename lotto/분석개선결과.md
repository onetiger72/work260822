# 본번호 적중 목표 로직 수정

기존 모델은 번호 순위 TOP6/TOP12 성과로 가중치를 정한 뒤, 검증하지 않은 조합 필터·동반출현 점수·보너스 관계·분산 벌점으로 최종 10세트를 선택했습니다. 시점별로 재현한 조합 필터는 최근 120회의 실제 당첨 조합 중 23개를 제외했습니다.

새 `main_hits_v2` 모델은 각 과거 회차 직전까지 계산한 분석값과 그 회차 본번호 결과로 최근 120회 학습 표본을 구성합니다. 정규화 회귀와 6/45 균등 기준으로의 수축으로 작은 표본 차이를 억제합니다. 본번호 6개 일치에 맞춰 보너스 보조 기법과 보너스 조합 점수를 제외하고, 홀짝·합계·직전 회차 중복에 의한 조합 배제도 제거했습니다.

후보 10세트 선택에는 모의 추첨에서 세트 중 최고 적중수의 효용 증가를 사용합니다. 0~6개 일치의 효용은 사전에 고정한 0, 1, 3, 9, 27, 81, 243입니다. 더 많은 본번호를 한 세트에서 맞추는 경우에 큰 가치를 주지만, 유한한 모의 표본과 가중 샘플링을 사용하므로 이는 근사적인 선택 기준입니다. 실제 6개 적중 확률의 계산식은 아닙니다.

1181~1240회 60회에 대해 각 대상 회차를 학습에서 제외하고 전체 10세트를 다시 생성했습니다. 기존 방식은 후보 시도 15,000개를 유지했고, 생성 시점 증빙이 없는 실시간 CSV 피드백과 GPT 가중치 변경은 비교에서 제외했습니다. 새 방식은 결과를 보고 설정을 재탐색하지 않았습니다. 이 자료는 과거 재현 검증이며 앞으로 수집할 실전 성과를 대체하지 않습니다.

| 세트당 평균 본번호 적중 | 0.7667 | 0.7933 | 0.8035 |
| 회차별 최고 적중수 평균 | 2.0500 | 2.2000 | 2.0853 |

| 5개 이상 적중 회차 | 0 | 0 | 0.02 |
| 6개 적중 회차 | 0 | 0 | 0 |

수정 방식의 이번 표본 최고 적중수는 개선되었지만, 세트당 평균 적중은 무작위 기준을 넘지 않았습니다. 5개와 6개 일치 개선은 관측하지 못했습니다. 따라서 구조적 오류 수정과 재현 가능한 평가 도입으로 판단해야 하며 당첨 우위가 입증된 것으로 해석하면 안 됩니다. 상세 회차별 결과는 `portfolio_evaluation.json`, 기존 결과는 `legacy_holdout.json`에 있습니다.

1241회부터 기존 `종합점수` 열의 의미는 모델이 추정한 본번호 적중수의 합입니다. 0.83은 83% 당첨 확률이 아닙니다. 과거 행의 점수 값은 원래대로 보존하므로 서로 다른 모델 점수를 직접 비교하지 마세요.

기본 실행 파일의 새 번호 생성 함수도 수정 모델로 연결했습니다. 과거 예측을 다시 바꿀 때는 `python -B lotto/regenerate_predictions.py --target 1241`로 먼저 후보와 입력 해시를 생성합니다. 검토 상태를 기록한 후 `replace_prediction_csv.mjs --apply`로 해당 회차만 백업 후 교체합니다. 다른 회차, 이력 데이터, CSV 열 구성을 보존하며 실제번호와 적중수는 결과 발표 전까지 빈칸으로 둡니다.
